## 자료형 정리
| 자료형     | 순서       | 중복     | 변경 가능 | 예시 사용              |
| ------- | -------- | ------ | ----- | ------------------ |
| 리스트 \[] | O        | O      | O     | 입력, 정렬, 순회         |
| 튜플 ()   | O        | O      | X     | 좌표, 회의 시작/끝, 함수 반환 |
| 세트 {}   | X        | X      | O     | 중복 제거, 집합 연산       |
| 딕셔너리 {} | O (3.7+) | 키 중복 X | O     | 빈도 계산, 매핑          |

- 리스트 ➡ 순서 있고 바뀔 수 있는 묶음
- 튜플 ➡ 순서 있고 바뀔 수 없는 묶음
- 세트 ➡ 순서 없고 중복 없는 묶음
- 딕셔너리 ➡ key:value 쌍으로 묶음
<br><br><br>

### 1️⃣ 리스트 `[]`
- 정의: 순서가 있는 <b>변경 가능한(mutable)</b> 자료구조
- 특징:
  - 값의 중복허용
  - 값 추가/삭제/수정 가능
  - 인덱스로 접근 가능
- 예시:
  ```python
  numbers = [1, 2, 3, 4]
  numbers.append(5)  # [1, 2, 3, 4, 5]
  numbers[0] = 10  #[10, 2, 3, 4, 5]
  ```
- 코테: 입력 저장, 순회, 정렬
<br>

### 2️⃣ 튜플 `()`
- 정의: 순서가 있는 <b>변경 불가능(Immutable)</b> 자료구조
- 특징:
  - 값 추가/삭제/수정 불가능
  - 리스트보다 메모리 효율이 좋음
  - 딕셔너리의 key나 set의 요소로 사용 가능
- 예시:
  ```python
  point = (2, 3)
  # point[0] = 5 ➡ 에러 발생
  x, y = point  # 튜플 언패킹 가능
  ```
- 코테: 값 묶어서 전달
<br>

### 3️⃣ 세트 `{}`
- 정의: 순서 없는 <b>중복 없는 집합 자료형</b>
- 특징:
  - 값의 중복 자동 제거
  - 순서 없어서 인덱스로 접근 불가
  - 교집합, 합집합, 차집합 연산 가능
- 예시:
  ```python
  s = {1, 2, 3, 4}  # {1, 2, 3}
  s.add(4)  #{1, 2, 3, 4}
  s.remove(2)  @{1, 3, 4}
  ```
- 코테: 중복 제거, 집합 연산
<br>
  
### 4️⃣ 딕셔너리 `{key: value}`
- 정의: 키와 값이 쌍으로 저장되는 <b>매핑 자료형</b>
- 특징:
  - 키(key)는 중복 불가
  - 값(value)은 중복 허용
  - 순서 있음 (Python 3.7+)
- 예시:
  ```python
  person = {'name': 'Alice', 'age': 25}
  print(person['name'])  # Alice
  person['age'] = 26
  ```
- 코테: 빈도 계산, 매핑 문제
<br><br><br>
